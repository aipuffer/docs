AI Puffer is a WordPress plugin that adds AI tools to your website and admin area.

Connect **AI Puffer Cloud** to start without an API key, or use your own provider credentials. Choose a supported model for each feature and use the tools through WordPress pages, shortcodes, blocks, products, and scheduled tasks.

Eligible verified Cloud accounts receive **25 free credits per month**. **Pro**, **Pro Plus**, and **Pro Max** unlock the same Pro features. Plus includes **3,000 AI credits monthly** and Max includes **10,000**. Cloud is optional on every plan; one-time top-ups remain available. See [Plans and Credits](/plans-and-credits).

You can use AI Puffer to add a chatbot, write posts and product content, build AI forms, generate images, run recurring automations, index knowledge sources, and track usage.

The main modules are Chatbots, Content Writer, Automations, AI Forms, Images, Knowledge Base, and Usage. Each module has its own settings, but they share the same provider connections and usage records.

Use **AI Puffer > Settings > Modules** to choose which modules appear in the AI Puffer navigation.

AI Puffer supports providers and services such as AI Puffer Cloud, OpenAI, Google, Azure, OpenRouter, xAI, DeepSeek, Ollama, Anthropic, ElevenLabs, Replicate, Pinecone, Qdrant, and Chroma. Availability depends on the module and the provider features you enable.

Usage shows your Cloud balance and requests, plus local activity logs. Optional WordPress user balances, pricing rules, and WooCommerce credit packages are separate from Cloud credits.
