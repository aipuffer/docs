AI Puffer can be installed from the WordPress plugin directory or uploaded as a ZIP file.

Use the free version first if you want to test the plugin before buying a paid plan. Pro, Pro Plus, and Pro Max use the same premium ZIP file. See [Plans and Credits](/plans-and-credits) to compare them.

## Install the free version

1. Open your WordPress admin dashboard.
2. Go to **Plugins > Add New**.
3. Search for **AI Puffer**.
4. Click **Install Now**.
5. Click **Activate** after the installation finishes.

<Frame>
  <img src="/images/screenshots/installation/add-plugin-search-ai-puffer.png" alt="AI Puffer in the WordPress Add Plugins search results" />
</Frame>

<Info>
If the button says **Active**, the plugin is already installed and active on that site.
</Info>

After activation, open **AI Puffer** from the WordPress admin menu.

## First-time setup

After activation, onboarding guides you through **Your goals**, **Connect AI**, and **First result**.

<Frame>
  <img src="/images/screenshots/cloud/onboarding-goals.png" alt="Onboarding goals for chatbot, writing, product descriptions, automations, and AI Forms" />
</Frame>

1. Choose the tools you want to use. You can enable more later in **Settings > Modules**.
2. Choose **AI Puffer Cloud** to start without an API key, **I have my own API key** to connect a provider account, or skip setup to configure it later.
3. For Cloud, check the email address, accept the connection terms, and click **Connect**. Marketing email consent is optional.
4. If asked to verify your email, open the Freemius confirmation message and confirm the address. Return to onboarding and click **I’ve verified my email**. Use **Resend email** if you need another message.
5. Once connected, try the first result offered for your chosen tool: a chatbot reply, a draft, a product description, an AI form, or a blog-post automation.
6. Complete or skip that result to enter the main dashboard. Review generated content before publishing it.

If your Freemius email is already verified, connecting normally does not require another email confirmation. In **I have my own API key**, switching providers loads that provider’s own key state; enter and check each provider separately.

Cloud’s eligible free monthly allowance is **25 credits**. Plus and Max also include monthly plan credits. The number of replies, drafts, or images a balance covers depends on the selected models and requests. Pro features require Pro, Pro Plus, or Pro Max, whichever AI connection you use.

See [Cloud connection and account settings](/cloud) or [direct provider setup](/ai-providers).

## Upload a plugin ZIP file

Use this method if you downloaded the plugin ZIP from WordPress.org, your purchase email, or the User Portal.

1. Open your WordPress admin dashboard.
2. Go to **Plugins > Add New**.
3. Click **Upload Plugin**.
4. Choose the plugin ZIP file.
5. Click **Install Now**.
6. Click **Activate Plugin**.

<Frame>
  <img src="/images/screenshots/installation/upload-plugin-zip.png" alt="WordPress Upload Plugin screen" />
</Frame>

<Tip>
Upload the `.zip` file directly. Do not unzip the plugin before uploading it to WordPress.
</Tip>

## Upgrade from Free to Pro

You can upgrade from inside WordPress or from the AI Puffer website.

### From WordPress

1. Install and activate the free version.
2. Open **AI Puffer** in the WordPress admin menu.
3. Click **Upgrade**.
4. Choose **Pro**, **Pro Plus**, or **Pro Max**, the billing period, and **Single Site** or **2 Sites**. Lifetime is available for Pro only and excludes monthly plan credits.
5. Complete checkout.

<Frame>
  <img src="/images/screenshots/installation/ai-puffer-upgrade-menu.png" alt="AI Puffer Upgrade link in the WordPress admin menu" />
</Frame>

After checkout, you will receive an email with your license key and the Pro plugin download link.

### From the website

1. Open the [AI Puffer pricing page](https://aipower.org/pricing/).
2. Choose Pro, Pro Plus, or Pro Max, your billing period, and the number of sites.
3. Complete checkout.
4. Check your email for the license key and Pro plugin download link.

## Safari ZIP setting

If you use Safari on macOS, make sure Safari does not automatically unzip downloaded files.

1. Open Safari.
2. Go to **Safari > Settings**.
3. Open the **General** tab.
4. Turn off **Open "safe" files after downloading**.

WordPress needs the `.zip` file. If Safari already extracted it, download the file again after changing this setting.
